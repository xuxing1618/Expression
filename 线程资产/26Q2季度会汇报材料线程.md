# 26Q2 季度会汇报材料线程

## 线程主题

26Q2 撰写季度会汇报材料

## 线程 ID

019ef8ac-13cb-7383-9d09-3a352fcda322

## 场景识别

- 沟通任务：汇报同步
- 对象：协作方 / Leader
- 媒介：飞书 / 文档
- 压力：低压力
- 风格：低压力同步 / 资深判断

说明：

本线程是季度末面向协作方或 Leader 的阶段复盘同步，目标是形成 Q2 结果、Q3 方向和后续对齐入口。

## 用户目标

把 Q2 工作和 Q3 规划从零散事实整理成适合季度会、飞书同步和协作方对齐的表达。

## 原始输入摘要

用户需要把 Q2 商家体系化、ODS 引用率治理、Spectra AI Coding 等工作同步给协作方，并判断是否需要单独发送。

## 表达策略

- 主动定义贡献：不只写做了哪些事，而要写这些动作产生了什么结果。
- 裁剪信息：只保留对协作方或 Leader 有认知价值的内容。
- 降低压力：用“同步”替代“汇报”，避免让对方产生必须正式回复的压力。
- 轻量结构：采用“回顾总结 -> 反思复盘 -> Q3 规划”的结构。
- 保留对齐入口：结尾强调“不用专门回复”，同时表达后续希望继续对齐。

## 优化输出

> 不用专门回复哈，主要是同步下阶段进展，后续 Q3 重点方向也希望多跟你对齐。

## 沉淀内容

- 季度会表达不能只写“做了什么”，要写“产生了什么结果”。
- 技术工作要被定义成业务收益、技术收益和协作收益。
- Highlight 要体现结果归因，Lowlight 要体现根因、影响和修正动作。
- 面向不同对象时，要裁剪对方不关心的信息。
- 飞书同步不是缩小版 PPT，而是低压力主动同步。

## 资产颗粒归类

### 内部表达资产

- 判断原则：组织场汇报不是证明忙，而是定义结果和影响。
- 判断原则：对方不关心的信息，不要为了完整而保留。
- 表达规则：执行动作要升级为结果表达，即“通过什么机制，使什么结果变好”。
- 表达规则：发给非直属但相关的协作方时，用“同步”降低对方压力。
- 表达结构：阶段复盘可采用“回顾总结 -> 反思复盘 -> 下一步规划”。
- 场景方案：季度末面向协作方的阶段复盘同步方案。
- 风格模式：低压力同步、资深判断。

### 外部内容资产

- 内容选题：职场汇报别再只写“我做了什么”了。
- 推送卡片：已生成“汇报不要只写做了什么”内部认知推送。
- 发布稿：已生成小红书发布版，状态为未发布。

## 可复用规则

- 汇报同步优先回答：做了什么、通过什么机制、结果如何变化、产生什么影响。
- 阶段复盘优先使用“回顾总结 -> 反思复盘 -> 下一步规划”的轻量结构。
- 发给非直属协作方时，用低压力同步保留对齐入口。
- 对方不关心的 O 或细节，不要为了完整而保留。
- 季度会材料要优先呈现结果、归因、证据和后续计划。

## 典型样例

原始输入：

用户需要把 Q2 工作成果和 Q3 规划同步给协作方，同时担心是否显得太正式或打扰对方。

场景判断：

汇报同步 + 协作方 / Leader + 飞书 / 文档 + 普通 + 低压力同步 / 资深判断。

表达策略：

用“同步”降低压力，用“回顾总结 -> 反思复盘 -> Q3 规划”组织信息，用结果和影响定义贡献，删去对方不关心的内容。

优化输出：

> 不用专门回复哈，主要是同步下阶段进展，后续 Q3 重点方向也希望多跟你对齐。

可复用规则：

当同步对象不是直属汇报链路，但与工作方向相关时，表达要兼顾结果呈现和关系压力控制。
